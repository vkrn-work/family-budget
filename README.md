# Конверты — семейный бюджет

Дашборд семейных трат по «конвертам»: у каждого конверта есть лимит на месяц, остаток переходит на следующий месяц, перерасход уменьшает следующий.

Открывается через GitHub Pages: `https://vkrn-work.github.io/family-budget/`.

## Что здесь лежит

- `index.html`, `app.css`, `app.js` — дашборд. Сборки нет, всё работает прямо в браузере. Графики — Chart.js из `vendor/`.
- `data/budget.json` — траты по конвертам и подкатегориям. Его выгружает основной (приватный) репозиторий: даты, суммы, конверты, подкатегории, названия сетей и мест. Адресов, номеров карт и счетов, имён людей здесь нет.
- `data/edits.json` — правки, сделанные в дашборде: трата перенесена в другой конверт, добавлена новая трата, удалена добавленная.

## Разделы

- **Конверты** — план, факт и тренд месяца; карточка каждого конверта со статусом («перерасход», «выйдет за план», «в плане», «экономия»). Неразобранные траты можно перетащить в конверт (на телефоне — долгое нажатие) или нажать на трату и выбрать конверт.
- **Анализ** — план, факт и тренд по конвертам, накопленные траты по дням, месяцы, подкатегории, места. Фильтры: конверт, кто платил, для кого, когда, источник, природа трат.
- **Операции** — список трат месяца с поиском; у каждой можно сменить конверт.

## Сохранение правок

Правки сразу видны на устройстве. В репозиторий они записываются через GitHub API, если на устройстве сохранён токен (кнопка состояния в шапке):

1. github.com → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → `family-budget`.
3. Permissions → Repository → **Contents: Read and write**.

Токен хранится только в браузере этого устройства. Без токена правки остаются на устройстве до тех пор, пока токен не будет добавлен.

## Как обновляются данные

Основной репозиторий забирает `data/edits.json`, переносит правки к себе, пересчитывает конверты и выкладывает свежий `data/budget.json`, а `data/edits.json` очищает.
