# Конверты (публичный дашборд) — инструкции для Claude

Репозиторий **публичный**, сайт — GitHub Pages. Отвечай владельцу по-русски.

## Что можно и нельзя класть сюда
- Только то, что выгружает основной репозиторий командой `fin.py sync-public`: даты, время, суммы, конверты, подкатегории, названия сетей и мест, короткие пометки.
- Нельзя: адреса (улицы, номера точек, банкоматов, отделений), номера карт и счетов, IBAN, имена и фамилии людей, сырые выписки. Перед каждым коммитом `data/budget.json` проверяй это поиском по `**`, `…`, `BY\d\d`, длинным числам и названиям улиц.
- Руками `data/budget.json` не правь — только через основной репозиторий.

## Правки из дашборда
- `data/edits.json` — журнал правок: `{op: "assign", id, sub, prev}`, `{op: "add", id: "n…", date, amount, label, sub, who, joint}`, `{op: "del", id}`; у каждой `uid`, `t`, `by`.
- Синхронизация делается из основного репозитория: `python3 analyst/fin.py sync-public <путь к этому репозиторию>` — применяет правки, пересчитывает, пишет `data/budget.json`, очищает `data/edits.json`. Перед этим `git pull` здесь, после — коммит в обоих репозиториях. Если между pull и push кто-то сохранил новую правку, push отклонится: сделай pull, снова sync-public и push.

## Устройство
- `index.html` + `app.css` + `app.js`, без сборки. Chart.js — `vendor/chart.umd.min.js`.
- Стиль — «жидкое стекло», тёмная тема, шрифт Urbanist, акцент оранжевый. Факт на графиках — синий `#3987e5`, план — нейтральный, статусы (перерасход, выйдет за план, в плане, экономия) всегда со значком и подписью.
- Конверты, лимиты и подкатегории приходят из `data/budget.json` (`envelopes`, `extra`). Тренд: `pace` — по темпу (дни / рабочие дни / выходные), `plan` — не меньше плана, `fact` — по факту.
